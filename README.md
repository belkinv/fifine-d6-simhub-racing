# Сцены LMU, ACC и AC EVO для FIFINE D6 / D6-Pro

Готовый переносимый комплект для FIFINE Control Deck и уже установленного SimHub.

В репозитории находятся:

- адаптированный StreamDeckSimHub 2.3.36 для FIFINE Control Deck;
- SimHub Property Server 1.16.13 с исправлением разрыва связи при одновременной подписке кнопок;
- сцена `Le Mans Ultimate` — 3 страницы;
- сцена `Assetto Corsa Competizione` — 3 страницы;
- сцена `Assetto Corsa EVO` — 3 страницы;
- установщик и проверка целостности.

Сам SimHub в репозиторий **не входит**, не скачивается и не переустанавливается.

## Что установить заранее

1. [SimHub](https://www.simhubdash.com/).
2. FIFINE Control Deck.
3. Подключить D6/D6-Pro и хотя бы один раз запустить FIFINE Control Deck.

Перед установкой закройте игры. Скрипт сам остановит SimHub и FIFINE Control Deck, сделает резервную копию заменяемых файлов и затем запустит программы снова.

## Установка

1. На странице репозитория нажмите `Code` → `Download ZIP`.
2. Полностью распакуйте ZIP в обычную папку.
3. Запустите `Install.cmd`.
4. Подтвердите запрос контроля учётных записей Windows.
5. Дождитесь сообщения `УСТАНОВКА ЗАВЕРШЕНА`.
6. В FIFINE Control Deck выберите сцену нужной игры.

Не запускайте `Install.cmd` непосредственно внутри ZIP-архива.

Установщик:

- проверяет контрольные суммы;
- прекращает установку, если SimHub не найден;
- не устанавливает и не обновляет SimHub;
- устанавливает Property Server и адаптированный плагин;
- устанавливает три сцены;
- ищет игры во всех библиотеках Steam и корректирует пути автоматического переключения.

## Проверка

Запустите `Verify.cmd`. Проверяются:

- версии и контрольную сумму исправленного Property Server, а также версию StreamDeckSimHub;
- наличие трёх сцен и трёх страниц в каждой;
- соединение с Property Server на порту 18082, если SimHub запущен.

Затем в игре проверьте живые значения: передачу, скорость, топливо, позицию, ABS, TC, баланс тормозов, флаг и лимитер.

## Резервная копия

Старые версии заменяемого плагина и трёх сцен сохраняются в:

`Документы\FIFINE-D6-Backup\дата-время`

Другие пользовательские сцены не удаляются.

## Особенности ACC

- `ЗЕРКАЛО` использует `F11` и управляет виртуальным зеркалом ACC.
- `РЕПЛЕЙ` использует `Ctrl+R`; в некоторых состояниях ACC команда может не открыть меню повтора.
- `ЧАТ 7`, `ЧАТ 8`, `ЧАТ 9` оставлены без текста, чтобы владелец ввёл свои сообщения.

## Ручная настройка Assetto Corsa EVO

Установщик не меняет настройки управления AC EVO. Телеметрия работает через SimHub, а игровые команды нужно один раз назначить вручную.

Точная таблица находится в [AC-EVO-MANUAL-BINDINGS-RU.md](AC-EVO-MANUAL-BINDINGS-RU.md). В меню управления игры выберите функцию и нажмите соответствующую кнопку D6. Сцена отправит назначенную клавишу `F13–F24` или `NUMPAD0–NUMPAD9`.

Если включён помощник `Automatic Pit Limiter`, лимитер автоматически действует только на пит-лейне. Для полностью ручного управления кнопкой D6 отключите этот помощник.
